# 01 搜索对象模型

本文件定义 04 检索层最基础的一条“产品检索记录”。

核心原则：

> 产品知识库是真实数据源；检索记录只是由真实产品资料自动派生出来的搜索数据。

当前检索粒度固定为：

```text
产品货号 + 工厂报价
```

同一产品货号如果有多个工厂报价，应展开成多条独立检索记录。

---

## 一、每条检索记录包含什么

```text
产品检索记录

身份信息
├─ 产品品类
├─ 产品货号
└─ 工厂名称

产品信息
├─ 产品主图
├─ 功能标签
├─ 场景标签
├─ 特殊属性
├─ 性能属性
└─ 可关联包装货号

工厂报价信息
├─ 主材质
├─ 详细材质
├─ 价格
├─ 起订量
├─ 尺码体系
└─ 尺码范围

自动派生的检索信息
├─ 检索关键词
├─ 语义检索文本
├─ 语义向量引用
└─ 检索记录版本
```

---

## 二、真实字段与派生字段必须分开

### 真实字段

来自 Product_KB，例如：

- 产品货号
- 工厂
- 材质
- 价格
- 起订量
- 尺码
- 功能标签
- 场景标签
- 性能属性
- 图片

这些字段不得由搜索层自行改写。

### 派生字段

由搜索层根据真实字段自动生成，例如：

- 检索关键词
- 语义检索文本
- 向量
- 检索版本号

这些字段：

- 可以重新生成；
- 不作为业务事实真源；
- 不允许反向覆盖 Product_KB。

---

## 三、关键词不是人工逐款维护

关键词应从真实产品资料自动提炼。

例如产品资料里有：

```text
PU
高回弹 PU
Gel
透气
缓震
轻度足弓支撑
```

系统可自动生成：

```text
PU
Gel
高回弹
透气排湿
缓震
回弹
足弓支撑
轻度支撑
```

关键词提炼必须遵守 02 的标准词和同义词规则。

---

## 四、语义检索文本不是原始资料复制

语义检索文本用于向量检索，应由系统自动把产品真实信息组织成一段简短、稳定、可比较的产品描述。

例如：

```text
PU 鞋垫，具有透气、缓震、较好回弹和轻度足弓支撑，
软硬适中，偏日常舒适和长时间行走使用。
```

要求：

- 只使用已有产品事实和已确认标签；
- 不编造未确认场景；
- 不加入价格、起订量等精确数值条件；
- 不加入营销夸张词；
- 不加入客户特定信息。

---

## 五、同一货号多工厂

例如：

```text
F0228 + 工厂A
F0228 + 工厂B
```

必须形成两条独立检索记录。

产品层语义内容可以相同或大部分相同，但工厂报价字段必须保持独立。

---

## 六、包装边界

当前产品检索记录只保留：

```text
可关联包装货号
```

不提前生成：

```text
产品 × 工厂 × 包装
```

的全部组合。

未来包装知识库启用后，在查询结果阶段动态组合。

---

## 七、核心原则

1. 产品知识库是真源。
2. 检索记录是派生数据。
3. 关键词和语义文本都自动从产品资料生成。
4. 向量只服务于检索，不反向修改产品资料。
5. 同一货号多工厂必须独立搜索。
6. 所有检索派生数据都应该能够重建。
