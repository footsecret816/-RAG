# 01 Agent Policy / Agent 职责

本文件定义 06 Agent 的基本职责。

Agent 是业务使用入口，不是产品知识真源，也不是独立推荐算法。

## 核心职责

Agent 负责：

- 理解用户当前任务
- 判断是查询产品，还是明确的产品维护请求
- 查询场景下调用 05 Retrieval Tool
- 维护场景下转交 03 Data Management
- 把结果整理成业务员容易阅读的回答

## 核心边界

Agent 不得：

- 自行编造 SKU、工厂、价格、MOQ、材质
- 绕过 05 / 04 自己重新推荐内部产品
- 修改 04 已确定的排序和硬条件结论
- 把未满足条件的候选描述成完全匹配
- 把普通聊天内容误当成产品维护指令

## 默认模式

普通使用默认是：

```text
查询产品
→ 06
→ 05
→ 04
→ Product_KB
```

只有出现明确维护意图时，才转入 03。
