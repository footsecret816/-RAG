# 标签定义规则

## 目标

保证产品知识库中的标签稳定、统一、可检索，避免同一概念被多种写法重复记录。

## 基本规则

1. 一个概念只保留一个标准标签。
2. 同义词、近义词、口语表达不得重复建立为多个标准标签。
3. 标签命名应简短、明确、稳定。
4. 标签尽量描述事实，不使用模糊营销词。
5. 不同类型的信息必须分层管理，不混用。

## 标签类型

### 产品层标签
- 功能
- 使用场景
- 性能属性

### 工厂供应层字段
- 工厂
- 材质
- 价格
- MOQ
- 尺码体系
- 尺码范围

## 示例

正确：

标准标签：
- 足弓支撑

近义表达：
- 支撑足弓
- 足弓承托
- Arch Support

错误：

同时建立：
- 足弓支撑
- 足弓承托
- 支撑足弓
