# 近义词与自然语言映射规则

## 目标

业务员可以自由使用自然语言提问，不要求使用标准标签。

系统负责把不同表达转换成内部标准标签或标准条件。

## 基本原则

1. 用户表达与内部标准词表分离。
2. 一个标准标签可以对应多个自然语言表达。
3. 自然语言映射可以是一对一，也可以是一对多。
4. 不确定时不强行映射，应保留模糊语义进入后续语义检索。
5. 映射结果必须服从数据 Schema，不允许生成不存在的字段。

## 示例

用户表达：

“支撑强一点”

系统标准化：

Arch_Support = 强支撑

用户表达：

“不要太软”

系统标准化：

Softness 偏向较低数值

用户表达：

“适合户外走很多路”

系统可能映射：

Scenario_Tags:
- 户外
- 长距离行走
