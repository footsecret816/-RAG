# 产品知识库与智能检索系统

这是一套**平台无关**的企业产品知识库与智能检索系统。

目标：
- 让业务员通过自然语言提出产品需求；
- 系统从真实产品知识库中检索合适的产品；
- 同一 SKU 可以关联多个工厂供应方案；
- 支持 MOQ、价格、材质、尺码等硬条件筛选；
- 支持功能、场景、相似定位等模糊语义检索；
- 最终以“SKU + 工厂供应方案”的粒度返回结果；
- 整套系统可接入不同智能体平台的 Agent。

## 当前总体架构

1. `01-schema/`  
   产品数据结构标准。定义 SKU 产品层与 Factory Offer 工厂供应层。

2. `02-taxonomy-rules/`  
   标签体系与业务规则。包括功能、场景、尺码/市场映射、检索条件解释等。

3. `03-data-management/`  
   产品数据新增、修改、删除、校验与索引更新机制。

4. `04-search/`  
   检索引擎。包括 Metadata 精确筛选、关键词检索、Vector 语义检索与 Ranking 排序。

5. `05-retrieval-tool/`  
   产品检索工具。把底层检索能力封装成 Agent 可调用的统一工具。

6. `06-agent/`  
   Agent 调用逻辑、指令与输出格式。

7. `07-tests/`  
   测试问题、标准结果与检索效果评估。

8. `docs/`  
   系统架构、实施说明、更新记录等文档。

## 数据边界

真实产品数据不进入本仓库。

实际产品资料应独立保存在本地或公司指定存储位置，例如：

```text
Product_KB/
├── SKU-001/
│   ├── product.md
│   └── main.jpg
├── SKU-002/
│   ├── product.md
│   └── main.jpg
└── ...
```

本仓库只管理：
- 数据结构
- 标签与规则
- 检索逻辑
- 数据管理逻辑
- Agent 调用方式
- 测试与文档
