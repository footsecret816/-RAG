# Insoles / 鞋垫类业务知识 V1

本目录是当前润通 Product Profile：`Product_Category = 鞋垫`。

目标：把业务员自然语言稳定转换成鞋垫知识库中的标准材质、功能、场景、特殊属性、性能条件和检索条件。

当前结构：

1. `profile.yaml`：可执行 Product Profile 真源
2. `01-material-mapping.md`：材质词表说明
3. `02-function-tags.md`：功能标签说明
4. `03-scenario-tags.md`：场景标签说明
5. `04-special-features.md`：特殊属性说明
6. `05-performance-attributes.md`：性能指标说明
7. `06-business-concept-mapping.md`：业务概念映射

真实 SKU、真实工厂、真实价格、MOQ、产品图片不进入本目录。

未来替换其他公司/产品时，应新增或替换 Product Profile，不修改 Core。
